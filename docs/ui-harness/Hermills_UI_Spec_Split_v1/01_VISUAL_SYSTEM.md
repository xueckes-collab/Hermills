# 01_VISUAL_SYSTEM.md

文档定位：Hermills 的全局视觉系统。  
适用对象：前端实现 Agent、设计 Agent、组件实现 Agent、验收 Agent。  
依赖文件：先读 `00_UI_MAP.md`，再读本文件。  
本文件专门定义颜色、字体、圆角、阴影、间距、动效、品牌气质和视觉禁区。

---

# 1. 视觉风格名称

Hermills 的视觉风格名称是：专业外贸 AI 工作台。

英文可以理解为 Professional AI Outreach Workbench。

这个风格不追求炫酷，不追求赛博朋克，不追求像游戏界面，不追求像 AI 聊天玩具。它追求的是清楚、稳定、专业、可信、低噪音、每天可用、有一点智能感，但不吓人。

用户打开 Hermills 时，应该感觉像打开了一张整理好的外贸销售工作桌。左边是工具目录，中间是今天要做的事情，右边或下方是 AI 给出的证据、评分和建议。软件应该像一个可靠的外贸助理，而不是一个需要用户学习技术概念的复杂系统。

---

# 2. 第一眼画面原则

登录后的主界面第一眼应该是浅灰蓝背景上的专业桌面工作台。

左侧导航是白色，干净、固定、稳定。顶部有品牌区，导航项整齐排列。当前页面用浅蓝底和蓝色边框标记，让用户一眼知道自己在哪里。

主内容区不是纯白一大片，而是浅灰蓝背景上放白色卡片。页面顶部有清楚的大标题和一句简短说明。主要动作按钮是深蓝色，安静但明确。复杂信息被拆成卡片、时间线、评分、证据块，不是一整段文字。

用户不应该在第一眼看到密密麻麻的设置、日志、模型参数、SMTP 主机、API Key、token、任务栈或数据库字段。技术信息只在系统设置、诊断或高级设置中出现。

---

# 3. 品牌气质

Hermills 的品牌气质是清楚、稳定、专业、不吓人、有智能感但不炫技、外贸销售每天愿意打开。

Hermills 不应该像开发者控制台。不要让用户感觉自己正在调试一个本地服务。Hermills 不应该像玩具式 AI 工具。不要用太多渐变、插画、emoji、悬浮泡泡和夸张动效。Hermills 不应该像传统老旧后台。不要使用过于硬的表格、灰黑色块、密集边框和默认浏览器表单。

Hermills 应该像一个懂外贸开发信的销售操作系统。它应该让用户感觉：我在做客户开发，不是在操作工程系统。

---

# 4. 颜色系统

主背景色使用浅灰蓝，不使用纯白铺满全页面。纯白只用于卡片、输入框、邮件正文、弹窗、详情面板和其他需要承载内容的区域。

主操作色只能用蓝色。主按钮、当前页面、核心操作和工作流进度使用蓝色。紫色只能用于 AI 智能提示、模型建议、质量分析、智能解释这类小面积强调，不得作为整页大面积主色。绿色只用于成功、可发送、已连接、已完成。黄色或橙色用于需要审核、等待处理、警告。红色只用于失败、危险、删除、不能发送。

不要为了让页面看起来丰富而随意增加颜色。Hermills 的高级感来自克制、层级和稳定，不来自色彩数量。

---

# 5. 颜色使用画面感

主背景应该像一张干净的浅灰蓝工作台，不刺眼，不冷硬。白色卡片像放在桌面上的任务纸张，每张卡片边缘清晰但不厚重。蓝色按钮像一个明确的启动控制键，不发光、不跳动，但用户一眼知道它是当前要点的动作。

状态色应该像轻声提醒，不像警报器。成功不是整块大绿，而是浅绿底、绿字和小 check。失败不是整页大红，而是红色边框、浅红背景、人话原因和下一步按钮。警告不是吓人，而是告诉用户“这里需要你确认”。

---

# 6. 字体系统

Windows 默认字体栈如下。

```css
font-family: Inter, "Segoe UI", "Microsoft YaHei UI", "Microsoft YaHei", system-ui, sans-serif;
```

中文优先使用 Microsoft YaHei UI / Microsoft YaHei，英文和数字优先使用 Inter / Segoe UI。字体应该清楚、干净、易读，不追求装饰性。

页面标题使用 28px、700、#0f172a。页面副标题使用 14px、400、#52627a。区块标题使用 18px、700、#0f172a。卡片标题使用 15px 到 16px、700、#102033。正文使用 14px、400、#31445f。重点正文使用 14px、700、#0f172a。辅助说明使用 13px、400、#64748b。元信息使用 12px、500、#718096。按钮文字使用 14px、700。Badge 使用 12px、700。

不要使用负字距。不要使用 viewport width 动态缩放字号。页面标题不要超过 30px。表格和卡片内文字保持 13px 到 14px。长邮件正文区域行高要舒服，建议 1.65。

---

# 7. 间距系统

基础单位是 4px。常用间距为 4px、8px、12px、16px、20px、24px、32px。

4px 用于图标和文字内部微距。8px 用于小组件内部距离、图标和文字间距、标签和文本之间。12px 用于按钮横向 padding、小卡片内部 gap、列表行内部紧密分组。16px 用于表单行 gap、卡片内部小分区、详情区段落间距。20px 用于普通卡片 padding。24px 用于页面 padding、主区块 gap。32px 用于大区块之间距离。

不要随手写 13px、17px、23px 这种没有体系的间距，除非是为了视觉微调并且有明确原因。间距系统越稳定，Hermills 越像一款真实的软件，而不是 AI 临时拼出来的页面。

---

# 8. 圆角系统

小按钮、小输入框、图标按钮使用 8px 圆角。普通卡片使用 10px。大容器、任务卡、上传区使用 12px。弹窗使用 14px。登录注册卡片使用 16px。状态胶囊使用 999px。

Hermills 不使用 20px 以上的大圆角作为常规风格。过大的圆角会让软件像移动端玩具或消费级 App，不像外贸业务员每天使用的桌面工作台。圆角应该让界面柔和但不幼稚。

---

# 9. 阴影系统

普通卡片阴影使用非常轻的层级感。

```css
box-shadow: 0 1px 2px rgba(15, 23, 42, 0.06);
```

主按钮 hover 可以使用轻微蓝色阴影。

```css
box-shadow: 0 8px 18px rgba(37, 99, 235, 0.20);
```

弹窗、抽屉、浮层可以使用中等阴影。

```css
box-shadow: 0 18px 50px rgba(15, 23, 42, 0.18);
```

禁止所有卡片都有浓重投影。禁止使用黑色大阴影制造廉价悬浮感。B2B 工具要稳，不要漂。

---

# 10. 图标系统

图标必须统一为线性图标。导航图标 18px。按钮图标 16px。状态小图标 14px 到 16px。空状态图标 40px。品牌图标 32px 容器。

图标 stroke 建议 1.8px 到 2px。图标不要太细，否则在 Windows 桌面端显示不清楚。不要混用线性图标、填充图标、彩色插画和 emoji。业务页面中不使用 emoji 作为功能图标。

图标只辅助理解，不抢文字注意力。按钮里图标和文字间距 8px。导航里图标和文字间距 10px 到 12px。

---

# 11. 动效系统

动效只用于反馈，不用于装饰。

hover 过渡 120ms。按钮 active 80ms 到 120ms。卡片进入 180ms。弹窗进入 160ms。页面内容淡入 120ms。loading spinner 800ms 一圈。skeleton shimmer 1200ms。批量结果新增卡片使用 180ms 淡入加 6px 上移归位。

推荐缓动：

```css
cubic-bezier(0.2, 0.8, 0.2, 1)
```

页面切换只做内容区域轻微淡入，不做大幅滑动。按钮 hover 可以轻微上浮 1px，active 下沉 1px。AI 时间线步骤完成时，蓝色 spinner 变绿色 check，文案不跳动。批量写好一封结果卡时，从顶部轻微淡入，但不强制滚动抢用户位置。

禁止弹跳、旋转入场、夸张缩放、霓虹扩散、循环发光、大范围滑动和装饰性动效。用户是来工作，不是来看动画。

---

# 12. 视觉禁区

禁止大面积紫色渐变。禁止赛博朋克霓虹光。禁止游戏 UI 式发光按钮。禁止所有卡片都有重阴影。禁止过大的果冻圆角。禁止大面积深蓝或黑色默认主题。禁止把 AI 结果显示成一段没有结构的长文本。禁止把系统日志、token、SMTP 参数、API 错误直接展示给业务用户。禁止为了好看加入无意义插画、emoji 和装饰图形。禁止每个页面像不同设计师做的。

禁止同一个页面出现多个同等强度的蓝色主按钮。每个页面或每个明确任务区只能有一个最强主操作。

禁止让错误提示悬浮遮挡内容。错误提示必须在正常文档流中出现，并给出恢复动作。

禁止让空状态只显示空白。空状态必须告诉用户下一步。

禁止让 loading 只显示一个孤立转圈。AI 生成和批量任务必须显示正在做什么。

---

# 13. 桌面端响应式视觉规则

Hermills 是 Windows 桌面软件，但窗口可能被用户缩小。

宽度大于 1180px 时，使用左侧导航 + 主内容 + 可选右侧详情区。宽度 920px 到 1180px 时，详情区下移或折叠成抽屉，统计卡变成 2 到 3 列，批量页面两栏变一栏。宽度小于 920px 时，左侧导航变顶部横向或折叠抽屉，所有双栏变单栏，按钮可换行但文字不能被截断。高度小于 760px 时，页面标题区压缩，卡片 padding 从 20px 降到 16px，底部操作条 sticky，保证主按钮可见。

响应式调整不能破坏工作流。缩小窗口后，用户仍然必须知道自己在哪里、下一步点哪里、当前任务状态是什么。
